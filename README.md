# NOUS – test inteligence

Webový IQ test v češtině, postavený na struktuře skutečných inteligenčních testů (WAIS-IV, Ravenovy progresivní matice, model CHC).

**Spuštění:** stačí otevřít `index.html` v prohlížeči – nebo online přes GitHub Pages: https://fandaverner.github.io/iqtest/

## Obsah testu (10 subtestů, cca 35 min)

| Oblast | Subtesty |
|---|---|
| Verbální porozumění (Gc) | Verbální analogie, Slovník |
| Fluidní a prostorové uvažování (Gf + Gv) | Maticové úlohy, Mentální rotace |
| Kvantitativní a logické uvažování (Gq) | Číselné řady, Logické úsudky |
| Pracovní paměť (Gwm) | Opakování čísel vpřed / pozpátku |
| Rychlost zpracování (Gs) | Hledání symbolů, Kódování symbolů |

Na začátku je dotazník (jméno, věk, vzdělání, jazyk, únava, zařízení…). Vyhodnocení obsahuje celkové IQ s percentilem a intervalem spolehlivosti, profil pěti indexů, GAI/CPI, silné stránky a rezervy, plusy a mínusy, doporučení k rozvoji a analýzu chyb.

Ukázka vyhodnocení: `index.html#demo`

## Omezení

Normy jsou orientační (odvozené z obtížnosti úloh a publikovaných výkonů v podobných testech), test nebyl standardizován na české populaci. Nejde o klinickou diagnostiku.
